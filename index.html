Method

What it counts

The day-to-day change in the combined size of all shielded pools: Sprout, Sapling, Orchard and Ironwood. A move from one pool to another cancels out, so a migration between pools is not counted as an inflow or outflow.

What it cannot show

Who moved the coins. Shielded transactions are private by design, so only totals entering or leaving the pools are visible.

Data and timing

Pulled from CipherScan’s public API and saved daily by a GitHub Action. The newest day may still be filling in, and per-pool history starts from the first snapshot.

Open data: daily_totals.csv and pool_snapshots.csv. Source code on GitHub.
